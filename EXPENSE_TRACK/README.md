# Finance Tracker 💰

## About the Project
Finance Tracker is a Python-based web application designed to help users manage their personal finances and track their expenses by using FLask and SQLAlchemy.

## Features
- User Registration
- User Login and Authentication
- Expense Management
- Add and View Expenses
- Expense Dashboard
- Individual Expense Details

## Technologies Used
- Python
- Flask
- HTML
- CSS
- JavaScript
- SQLite (if used)

## How to Run

1. Clone the repository.
2. Install dependencies:

```bash
pip install -r requirements.txt
```

3. Run the application:

```bash
python app.py
```

4. Open the local URL displayed in your terminal.
